# Security Policy

## Supported versions

Only the latest tagged release receives fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately
via [GitHub private vulnerability reporting](https://github.com/haiiibin/claude-multi-agent-investing/security/advisories/new)
or email haibiny123@gmail.com. You can expect an initial response within a few
days.

## Scope notes

This repository contains Claude Code agent and command definitions plus helper
scripts. It runs inside the user's own Claude Code session, holds no credentials
of its own, and does not place trades. Reports about prompt-injection paths
(for example, untrusted text in fetched data steering an agent toward an action
the user did not ask for) are particularly welcome.
